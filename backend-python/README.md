# MathMatrix Scientific Computing Server

Asynchronous Python FastAPI microservice powering numerical analysis, calculus, and Fourier transforms for MathMatrix.

## Capabilities
- **Discrete Fourier Transform (DFT):** Analyzes composite multi-frequency waveforms into harmonic constituent spectra.
- **Numerical Calculus Integration:** Evaluates definite integrals using high-precision Trapezoidal Riemann Quadratures.
- **Finite Difference Differentiation:** Central difference approximation for instantaneous rates of change.
- **Matrix Algebra Engine:** Multi-dimensional matrix multiplications, transformations, and scalar projections.

## Quickstart

```bash
pip install -r requirements.txt
python main.py
```
Server runs on `http://localhost:8002`.
