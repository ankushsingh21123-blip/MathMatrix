# MathMatrix 📐⚡

**MathMatrix** is an interactive visual laboratory designed to bring complex mathematical and probabilistic structures to life in real time. 

[![Live Demo](https://img.shields.io/badge/Live%20Demo-math--matrix--lab.netlify.app-00C7B7?style=for-the-badge&logo=netlify)](https://math-matrix-lab.netlify.app)
[![GitHub](https://img.shields.io/badge/GitHub-ankushsingh21123--blip%2FMathMatrix-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ankushsingh21123-blip/MathMatrix)

🌐 **Live Website:** [math-matrix-lab.netlify.app](https://math-matrix-lab.netlify.app)

<br/>

Built with React 18, Vite 6, TypeScript 5, Plotly.js, Recharts, KaTeX, and Tailwind CSS.

---

## 🔬 Explorations & Simulations

- 📈 **Calculus & Dynamic Tangents**: Visualize instantaneous rates of change, tangent slopes, and definite integration bounds interactively.
- 🌊 **Fourier Transform Synthesis**: Deconstruct complex waveforms into fundamental sine and cosine harmonics with real-time frequency-domain breakdown.
- 📊 **Probability Distributions**: Explore Gaussian, Poisson, Binomial, and Exponential distributions with live parameter scaling.
- 🎲 **Central Limit Theorem Engine**: Live Monte-Carlo simulations demonstrating convergence towards normal distribution across varying sample sizes.
- 📐 **Vector Fields & Multivariable Calculus**: Explore gradient vectors, divergence, and 3D contour planes.

---

## 🛠️ Multi-Language Architecture & Tech Stack

- **Frontend Visual Laboratory**: React 18 + Vite 6, TypeScript 5, Plotly.js, Recharts, KaTeX LaTeX typesetting, Tailwind CSS 3
- **Scientific Computing API (`backend-python/`)**: Python 3.12, FastAPI, Uvicorn, Discrete Fourier Transform (DFT), Numerical Calculus Quadratures, Matrix Linear Algebra
- **Numerical FFT Engine (`engine-cpp/`)**: Modern C++20, CMake, In-place Cooley-Tukey Radix-2 Fast Fourier Transform, Cache-friendly Matrix Dot Products

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/ankushsingh21123-blip/MathMatrix.git
cd MathMatrix
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
