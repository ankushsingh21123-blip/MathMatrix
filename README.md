# MathMatrix 📐⚡

**MathMatrix** is an interactive visual laboratory designed to bring complex mathematical and probabilistic structures to life in real time. 

Built with React 18, Vite 6, TypeScript 5, Plotly.js, Recharts, KaTeX, and Tailwind CSS.

---

## 🔬 Explorations & Simulations

- 📈 **Calculus & Dynamic Tangents**: Visualize instantaneous rates of change, tangent slopes, and definite integration bounds interactively.
- 🌊 **Fourier Transform Synthesis**: Deconstruct complex waveforms into fundamental sine and cosine harmonics with real-time frequency-domain breakdown.
- 📊 **Probability Distributions**: Explore Gaussian, Poisson, Binomial, and Exponential distributions with live parameter scaling.
- 🎲 **Central Limit Theorem Engine**: Live Monte-Carlo simulations demonstrating convergence towards normal distribution across varying sample sizes.
- 📐 **Vector Fields & Multivariable Calculus**: Explore gradient vectors, divergence, and 3D contour planes.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Language**: TypeScript 5
- **Visual Computing**: Plotly.js, React-Plotly, Recharts
- **Math Engine**: Math.js, Simple-Statistics, KaTeX LaTeX typesetting
- **Styling**: Tailwind CSS 3 + Framer Motion animations

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/ankushsingh21123-blip/MathMatrix.git
cd MathMatrix
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
